# Project documentation

`goflexlm` turns FlexNet Publisher debug logs into structured events and reads
supported FlexLM license documents. The library and log CLI use only the Go
standard library.

| Guide | Read it to |
| --- | --- |
| [Debug-log parser](log-parser.md) | Decode events in Go and understand timestamps, diagnostics, and JSON Lines |
| [License files](license-files.md) | Parse supported directives and understand license records, counts, and dates |
| [Command-line reference](cli.md) | Build and run the log-to-JSON command |
| [Development](development.md) | Find implementation code, run checks, and maintain compatibility |

Start with the [project README](../README.md) for a short introduction. All shell
commands in these guides assume the repository root as the working directory.
